When bumping the PaperMod submodule, diff that tail against the theme's file and re-sync it. The fork exists because the home branch cannot be overridden on its own, and two things were wrong with it for this site: 1. It set the Person's `image` to favicon.ico (the "C" mark) rather than the profile photo, so search engines and agents rendered the wrong face. 2. It carried name/url/description/sameAs and nothing else. The home page is intentionally the bare profile card, which leaves very little text for a crawler to read. This graph is how the page states who it is about instead: a ProfilePage whose mainEntity is a fully described Person. That is the schema.org pattern for a personal profile page, and unlike body copy it costs nothing visually. It does not make the page's *text* any longer, so it does not satisfy crawler heuristics that count rendered characters.
