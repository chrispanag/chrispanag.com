{{- /* Captioned image for page bundles. Resolves the named co-located resource, downsizes it to twice the 720px content width (--main-width) and serves AVIF with a same-format fallback through . AVIF encoding needs Hugo >= 0.162. Both variants go through the resource pipeline, so each URL is absolute and carries a content hash (…_hu_.). That matters twice over: the built-in `figure` shortcode emits `src` verbatim, so a relative src like "prelude-team.jpg" 404s on pages served without a trailing slash (e.g. /about) because the browser resolves it against the site root rather than the page bundle; and the hash busts the CDN cache whenever the source image changes. Params: src (required, matches a co-located resource), alt, caption. */ -}} {{- $src := .Get "src" -}} {{- with .Page.Resources.GetMatch $src -}} {{- $w := cond (gt .Width 1440) 1440 .Width -}} {{- $img := .Resize (printf "%dx" $w) -}} {{- $avif := .Resize (printf "%dx avif" $w) -}} {{- else -}} {{- errorf "photo shortcode: resource %q not found in page bundle %q" $src $.Page.File.Path -}} {{- end -}}
